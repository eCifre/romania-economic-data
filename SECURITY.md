# Security Policy

This repository contains static datasets and documentation — it does not run any code, so there isn't application attack surface here in the traditional sense.

If you've found a security issue relating to the **eCifre platform** (ecifre.ro or its API), **please do not open a public GitHub issue for it.** Public issues are visible to everyone, including anyone who might misuse the information before it's fixed.

Instead, please report it through the contact form on **[ecifre.ro](https://ecifre.ro)** (available in the site footer). We don't currently have a dedicated security-disclosure email published — use the general contact form and mention that it's a security report so it can be routed appropriately.

## What to include

- A clear description of the issue and its potential impact
- Steps to reproduce, if applicable
- Any relevant URLs, request/response examples, or screenshots

We appreciate responsible disclosure and will do our best to respond promptly.
