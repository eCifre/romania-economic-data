# Contributing

Thanks for your interest in this repository.

**This is a data repository, not the eCifre application.** The eCifre platform (website, API backend, mobile app, admin tools) is closed-source and is not developed here or in any other public repository. Please don't open issues or pull requests asking for application features, bug fixes in the eCifre product, or access to the source code — they'll be closed without action.

## What contributions are welcome

- **Documentation fixes** — typos, unclear wording, broken links in the README or `DATA_SOURCES.md`.
- **Dataset issues** — a value that looks wrong, missing, or inconsistent with the original source.
- **Source suggestions** — a Romanian or European public institution whose data you think eCifre should track.
- **New dataset requests** — a topic or indicator you'd like to see published here, if it isn't already.

## How to contribute

- **Open an issue** describing the problem or suggestion. For a data issue, please include: the file path, the row(s) in question, and (if possible) a link to the original source value you're comparing against.
- **Pull requests** are welcome for documentation fixes. Please don't submit pull requests that add or edit CSV files directly — dataset updates are generated from eCifre's own pipeline, not hand-edited.

## Reporting incorrect data

If a value in a dataset doesn't match what the source institution publishes, that's useful to know — please open an issue rather than silently forking a corrected copy, so the fix can be verified against the source and applied upstream.
