# Changelog

All notable changes to the **Romania Economic Indicators — eCifre** dataset are documented here. Versions follow a calendar scheme (`YYYY.MM`, e.g. `2026.09`); a new version is only published when the canonical export has actually changed since the last one (checked via a content hash before each release — see `scripts/publish_zenodo.py`).

## 2026.09 — pending first release

- Initial Zenodo release (not yet published — see the project's final report for what's still needed).
- 28 indicators
- 16,857 observations
- 43 geographic areas (Romania nationally, plus 42 counties)
- 8 source institutions: ANOFM, ANRE (natural gas), BNR, ENTSO-E, Eurostat, INSSE, Ministerul Finanțelor, ONRC
- Temporal coverage: 2012–2026 (varies by indicator — see `DATA_DICTIONARY.md`)
